## 关键配置说明

### 1. publicPath 配置差异

| 前端项目 | publicPath | 访问路径 | 说明 |

## 常见问题排查

### 问题1: 租户登录页面空白
**原因**: 直接访问 `/tenant/login` 会因为 publicPath 配置导致资源加载失败
**解决**: 必须访问 `/tenant/` 让 Vue Router 正确处理路由

### 问题2: 端口冲突
**原因**: Admin 和 Tenant 同时启动时，第二个服务会自动使用 8082 端口
**解决**:
- Admin 固定使用 8081
- Tenant 实际运行在 8082
- 或者分别指定不同端口启动

### 问题3: API 404错误
**原因**: 后端 Java 服务未启动或端口不对
**解决**:
1. 检查 Java 进程: `lsof -i :20108`
2. 检查 API 文档: `http://localhost:20108/swagger-ui.html`
3. 测试登录接口: `http://localhost:20108/api/tenant/login/info`

### 问题4: 前端热更新不生效
**原因**: Webpack HMR 缓存问题
**解决**:
1. 杀掉 dev server 进程
2. 清除 node_modules/.cache
3. 重新启动 `npm run serve`
